# Recourse frontend

Next.js (App Router, TypeScript, Tailwind). See the root README for the full stack.

```bash
npm install
npm run dev                        # http://localhost:3000
npm run lint
npm run build
```

`NEXT_PUBLIC_API_URL` (default `http://localhost:8000`) points at the API. It is inlined at build time, so set it before `npm run build`.
